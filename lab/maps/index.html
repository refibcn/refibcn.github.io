Maps

Two bespoke map components — not generic UI-kit material (they're one-off, domain-specific applications, not reusable atoms/molecules), but documented here because mapping is a recurring, load-bearing pattern across the site and worth keeping in view alongside everything else.

live

CatalunyaProgramMap

Interactive article-view map: MapLibre GL + hosted vector tiles (OpenFreeMap "positron"), constrained to Catalunya, comarca overlay, custom project markers with click-to-popover, province quick-zoom, L'Hospitalet shortcut, on-screen zoom controls. Desaturates the base tile style and hides OSM place labels to match the paper-and-ink palette.

Used in: atlas.astro. Props: projects: Project[], networks: Record<network, NetworkMeta>

CatalunyaInsetMap

Static-first d3 SVG map (no tile server) with a sub-zoom callout for L'Hospitalet metro, where 4 of 11 RC cohort markers cluster. Card ↔ marker linking: hovering a project card highlights its marker and vice versa.

Used in: projects/regenerant-catalunya (dashboard). Props: projects: Project[]

Gap: the two maps share almost no code (separate rendering stacks — d3/SVG vs. MapLibre/canvas, separate marker-color logic hardcoded per component rather than pulling from --lib-* tokens). If a third map ever gets built, that duplication is worth resolving first rather than forking a third time.
