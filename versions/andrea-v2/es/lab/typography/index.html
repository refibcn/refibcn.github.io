Typography

Two working families — Geist carries headings and body, Averia is the display face for special occasions — plus mono for labels/data. Family choice lives in src/styles/theme.css; the size scale and line-heights live in src/styles/tokens.css.

live

Families

Display — Averia Serif Libre

var(--serif), opted into with .display — special occasions only

Headings + body — Geist Variable

var(--sans), also var(--font-headings) — every heading level (h1–h6) and all body copy

Mono — IBM Plex Mono

var(--mono) · labels, code, addresses, chart data — labels always uppercase + tracked

How to use them

Geist is the default for everything text-shaped — headings and body both. If you're not deliberately reaching for the display treatment, you're already using the right font by doing nothing.

Averia is not "the heading font" — it's the display face, for the small number of special-occasion moments that want a bigger, editorial voice: a hero title, a page's opening H1, an occasional pull quote. Opt in explicitly with the .display class.

  • Averia is for ReFi BCN's own surfaces only — refibcn.github.io and other pages we own. This design system will end up serving client work and other engagements too; those don't inherit our display face. Geist + mono travel; Averia stays ours.
  • Only h1, h2, h3 may use it — combine the heading tag with class="display". Never h4, h5, h6 — enforced in code, not just convention: h4.display / h5.display / h6.display are forced back to Geist even if .display gets added by mistake (src/styles/global.css).
  • .display also works on non-heading elements (a <p>, a monogram span) — it's a font/weight/line-height treatment, not something tied to heading semantics.

Live example: Hero's <h1 class="hero__title display"> — the only place on the real site currently using it.

Size scale

~1.22–1.25 step progression, --text-2xs (0.625rem / 10px) → --text-5xl (5rem / 80px). Base (--text-base) is 1.25rem / 20px — the L tier of the copy scale below. --text-copy-md (1.0625rem / 17px, the copy scale's M tier) sits outside this ladder, between base and sm.
