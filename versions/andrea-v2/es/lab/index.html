Overview

The living design system for refibcn.github.io — tokens, atoms, molecules, organisms, and the Catalunya map patterns, documented against what's actually wired into the Astro build.

This design is a work in progress. Pages here document what exists today and flag with a status tag what's unused, incomplete, or missing outright — this is meant to stay accurate as the visual direction keeps changing, not to lock anything in.

How this is organized

Atomic-design tiers, left rail. Each page: what exists, where it's used on the live site, and what's still a gap.

  • Foundations — reference docs: this overview, and how the section works.
  • Atoms — smallest reusable pieces: color, type, spacing/effects, motifs, image styles, buttons/links, controls (tabs, loading), badges, inputs.
  • Molecules — small compositions: cards, stat bands.
  • Organisms — full page sections: heroes, CTA bands, feature grids, nav, footer, and the Catalunya map components (d3 inset map + MapLibre program map) — not generic UI-kit material, but load-bearing across several pages and worth keeping in view alongside everything else.
